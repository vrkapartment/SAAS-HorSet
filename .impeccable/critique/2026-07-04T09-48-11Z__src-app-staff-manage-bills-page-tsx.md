## ⚠️ Priority Issues (Updated Action Plan)

### 🔴 [P0] ตารางแออัดด้วยฟิลด์อินพุตกรณีฉุกเฉิน (Persistent Inputs for Emergency Edits)
*   **Why it matters:** แอดมินไม่ได้มาจดมิเตอร์หน้านี้ แต่ตารางกลับแสดงช่อง Input ค้างไว้ตลอดเวลา ส่งผลให้เกิด Visual Noise และทำให้หน้าจอนี้ดูเหมือนเป็นตาราง Spreadsheet สลอปอัดแน่น แทนที่จะเป็นแดชบอร์ดสรุปผลบัญชีที่สะอาดหรูหรา
*   **Fix:** เปลี่ยนตัวแสดงเลขมิเตอร์ไฟฟ้า/น้ำ และวันจ่ายเลทในตารางให้แสดงเป็น **ข้อความธรรมดา (Read-only Text)** ที่ดูสงบ สะอาดตา และเพิ่มปุ่มไอคอน "แก้ไขกรณีฉุกเฉิน" เล็กๆ ท้ายแถว หรือให้ดับเบิ้ลคลิกเพื่อสลับเป็นช่องป้อนข้อมูล (Inline Double-click to Edit) เฉพาะตอนจำเป็นเท่านั้น
*   **Suggested command:** `/impeccable layout`

### 🟠 [P1] ขาดฟีเจอร์ดำเนินการกลุ่มเพื่อเพิ่มประสิทธิภาพ (Missing Bulk Actions)
*   **Why it matters:** ในช่วงสิ้นเดือนหรือต้นเดือน แอดมินต้องไล่คลิก "ออกบิล" ทีละห้อง หรือกด "ส่ง LINE บิล" ทีละห้อง ส่งผลให้กระบวนการจัดการช้ามากเมื่อมีห้องพักจำนวน 40-100 ห้องขึ้นไป
*   **Fix:** เพิ่มปุ่มกระทำการแบบกลุ่ม (Bulk Actions Area) ที่แถบด้านบนตาราง เช่น "ออกบิลสำหรับห้องที่เลือกทั้งหมด" หรือ "ส่ง LINE บิลทั้งหมดที่คำนวณแล้ว" ควบคู่กับช่องติ๊กเลือกแถว (Checkbox) หน้ารายชื่อห้อง
*   **Suggested command:** `/impeccable layout`

### 🟠 [P2] มลภาวะทางสายตาจากป้ายสถานะ (Over-emphasized Visual Density)
*   **Why it matters:** หน้าจอมีการใช้ป้ายสถานะ Badge และปุ่มจำนวนมากกองอยู่รวมกันในคอลัมน์เดียว ขยายความสูงของแถวตารางจนเบียดชิดกันเกินไป ทำให้ยากต่อการสแกนความถูกต้องของยอดรวมบิล
*   **Fix:** ซ่อนปุ่มย่อยที่ไม่จำเป็น (เช่น ปุ่มแก้ไขค่าปรับ, ปุ่มแก้ไขสลิปกรณีฉุกเฉิน) และจัดกลุ่มรวมอยู่ในปุ่ม "ปุ่มเมนูจุดไข่ปลา (...) ท้ายแถว" (Row Action Dropdown) เพื่อสงวนพื้นที่หน้าจอให้โปร่งสบายตาสุดพรีเมียม
*   **Suggested command:** `/impeccable layout`

### 🟡 [P3] การโต้ตอบธุรกรรมผ่าน Alert ระบบ (Native Browser Confirmation Dialogs)
*   **Why it matters:** เวลาแอดมินคลิกรับรองการเงิน "รับเงินแล้ว" หรือ "ปฏิเสธสลิป" ตัวแอปจะขึ้นข้อความแจ้งเตือนดั้งเดิมของเบราว์เซอร์ ซึ่งปิดกั้นการโต้ตอบอื่นและไม่พรีเมียม
*   **Fix:** เปลี่ยนไปใช้ Radix Dialog หรือโมดอลยืนยันที่จัดสไตล์เรียบหรูสว่าง/มืด เข้าคู่กับธีมหอพักของระบบ
*   **Suggested command:** `/impeccable harden`
